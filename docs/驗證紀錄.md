## 驗證範圍與限制

- 尚未在實體手機、Safari 或 Firefox 完成回歸測試，不宣稱所有裝置都能維持相同效能。
- 本環境使用軟體繪圖。正式遊玩建議開啟硬體加速；首次需要下載約 36 MiB 引擎。
- Godot 的 Dummy 音訊驅動在快速流程測試退出時有 AudioStream ObjectDB 清理警告，測試檢查仍全部通過；瀏覽器未出現相同執行錯誤。音效未經實體喇叭聽感評估。
- GitHub Pages 是否啟用及公開網址是否可用，與本機網頁版驗證是不同事項；見 [部署說明](網頁部署說明.md)。此交付不將 Git 推送成功當作網站發布成功。
