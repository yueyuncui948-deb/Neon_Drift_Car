# ION-01 模型與動畫來源

## 模型怎麼生成？

這台車是此專案原創的程序化模型，不是下載的車模，也不是圖片轉 3D。
`tools/build_car.py` 使用 Blender 的 Python API `bpy`，從空白場景建立：

- 自訂截面網格：楔形車身與多面座艙。
- 立方體與單段倒角：頭燈、燈條、側裙、後視鏡、尾翼、擴散器。
- 12 邊形圓柱：低多邊形輪胎、輪圈與輪轂。
- 長方體輻條：六輻輪圈。
- 8 種程式建立的材質：車漆、玻璃、橡膠、金屬及發光燈條等。

執行 `blender --background --python tools/build_car.py`，會更新 `art/neon_drift_car.blend`、`assets/cars/neon_drift_car.gltf` 與 `.bin`。這個指令會覆寫生成檔，手動改過 Blender 原檔時請先另存備份。

模型共 1,936 個三角形、84 個網格物件。沒有使用第三方貼圖或外部模型，亦沒有第三方資產授權依賴。

## 骨骼是哪裡來的？

**目前沒有骨骼、Armature、蒙皮權重或外部動作庫。** 車輛是硬表面物件，無需像人物一樣用骨骼變形。

生成腳本另外建立四個 Empty 空物件作為輪軸：`Wheel_FL`、`Wheel_FR`、`Wheel_RL`、`Wheel_RR`，並把各輪胎、輪圈、輪轂與輻條放到对应輪軸下。這些是我們自己建立的剛體旋轉樞紐，不是骨骼，也沒有從 Mixamo 等服務取得素材。

Godot 的 `scripts/car.gd` 在輪軸下建立 `Roll` 節點：

1. 前輪輪軸沿 Y 軸轉動，表現左右轉向。
2. 四輪的 `Roll` 沿 X 軸轉動，轉速依車速與輪胎半徑計算。
3. 車身視覺節點稍微傾斜，表現過彎重量轉移。
4. `CharacterBody3D` 與箱形碰撞體負責街機式行駛與碰撞。

這是程序化零件動畫，不是骨架動畫，也不是精密懸吊或輪胎物理模擬。Blender 原始朝向為 -Y、Z 向上；glTF 匯入後為 +Z 前方、Y 向上。
