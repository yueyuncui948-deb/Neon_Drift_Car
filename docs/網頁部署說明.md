# 霓虹甩尾：網頁版遊玩與部署

## 檔案位置

`docs/play/` 是已匯出的 Godot 4.6.3 WebGL 2.0 網頁版。使用單執行緒模板，不需要額外的 COOP/COEP 跨來源隔離標頭；PWA 與 Service Worker 未啟用。檔案應完整保留，不能只上傳 `index.html`。

- `index.html`：中文載入畫面與遊戲入口。
- `index.js`、`index.wasm`：Godot 網頁引擎。
- `index.pck`：遊戲場景、模型、音效及字型。
- 音訊 worklet 等輔助檔：保持同資料夾。
- `build-manifest.json`：版本、檔案大小與 SHA-256。
- `LICENSES.txt`：Godot、引擎相依項目及中文字型授權。

首次載入需下載約 36 MiB 引擎及遊戲資源，後續通常由瀏覽器快取。這是一款單人三圈計時遊戲，無需登入或後端伺服器。

## 在本機開啟

不要以 `file://` 雙擊 HTML；需透過 HTTP／HTTPS 伺服器提供檔案。

```bash
python3 -m http.server 8060 --directory docs/play
```

在本機瀏覽器開啟該伺服器，使用支援 WebGL 2.0 的近期瀏覽器；建議啟用硬體加速。手機建議橫向遊玩，操作說明見 README。

## 使用 GitHub Pages

推送程式碼不等於已啟用 Pages。此專案已備妥部署檔案，可在 GitHub 儲存庫中操作：

1. 開啟 **Settings → Pages**。
2. 在 **Build and deployment → Source** 選 **Deploy from a branch**。
3. 選擇 **main** 與 **/docs**，按 **Save**。
4. 等待 GitHub 顯示部署完成，使用 Pages 面板提供的網址。

`docs/index.html` 會導向 `play/`。之後每次將新的 `docs/play/` 推送到 `main`，Pages 會隨之更新。是否能啟用公開 Pages 取決於儲存庫可見性、GitHub 方案及管理權限。

這份文件不代表 Pages 已啟用或公網網址已驗證。請以 GitHub Pages 面板與實際開啟結果為準。

## 重新匯出

需要 Godot **4.6.3 stable** 與同版本 Web 模板。雲端不可寫入家目錄時，先照 README 設定 XDG 目錄，再執行：

```bash
python3 tools/install_web_templates.py
bash tools/export_web.sh
```

模板安裝程式從官方 HTTPS release 下載，核對官方 SHA-512 及各 Web 模板 SHA-256；已安裝且校驗一致時不重下載。首次完整模板封裝約 1.2 GB，安裝後只需保留 Web 模板。匯出會更新 `docs/play/`，完成測試後請一併提交推送。

## 瀏覽器回歸測試

安裝 Python Playwright 與 Chromium 後，先啟動上述 HTTP 伺服器，再執行：

```bash
python3 tests/test_web.py
```

測試透過鍵盤／滑鼠／多指觸控操作真正的 Chromium WebGL 遊戲，檢查起跑、加速、氮氣、甩尾、暫停、回正、實際駕駛三圈、結算、重新載入後紀錄保存，以及多指觸控。

`?qa=1` 只啟用唯讀狀態快照供測試觀察，沒有傳送位置、直接加圈、改計時器或跳關的控制介面。一般遊玩不需要此參數。雲端使用 SwiftShader 軟體繪圖測試，不能把它的幀率當作實體顯示卡效能。
